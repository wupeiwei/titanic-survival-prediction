## 这次做了什么

我用的是 pandas 和 scikit-learn，模型是随机森林，设置为 100 棵树，随机种子固定为 91。整个实验在 Kaggle Notebook 上运行，不需要 GPU。

之前写 C 时，我更习惯用循环处理数据。这里像 `fillna()`、`get_dummies()` 这样的操作，一行就能处理整列。读这部分代码时，我会把它拆回熟悉的步骤：哪一列是输入、哪些值被替换了、处理后多出了哪些列。这样比较容易跟上数据在代码里的变化。

现在的模型使用 5 个特征：

| 特征 | 我怎么处理 | 想让模型利用的信息 |
|---|---|---|
| Pclass | 保留舱位等级 | 不同舱位的差异 |
| Sex | 独热编码 | 性别 |
| Age_Bin | 按 0、12、18、60、100 的边界分箱 | 年龄阶段 |
| FamilySize | SibSp + Parch + 1 | 包括本人在内的家庭人数 |
| IsAlone | 判断 FamilySize 是否为 1 | 是否独自出行 |

训练和测试数据分别编码后，我用 `reindex(columns=x.columns, fill_value=0)` 对齐列。这里需要对齐的不只是列数，还包括列名和顺序，否则预测时的输入就可能和训练时对不上。

早先的版本还尝试过从姓名中提取头衔，以及对票价分箱。最新上传的代码简化成了上面的 5 个特征。两个版本都留在 Git 历史里，不过我还没有完整的对照实验，暂时不能说简化后一定更好。

## 回头检查时发现的问题

这次整理代码和说明，发现有些地方虽然能运行，原来的解释却不够准确。

比如年龄分箱，我之前把 `pd.cut` 写成了“等宽分箱”。但代码用的是自己指定的边界，各段宽度明显不同。函数叫什么和这次具体怎么用，需要分开看。当前区间默认左开右闭，年龄为 0 或超出边界时也需要额外处理。

缺失值填充也需要区分实验目的。当前版本用全部已标注训练数据的年龄中位数统一处理训练、验证和测试数据，这是我这次保留的实验口径。严格评估时，更稳妥的做法是只用训练子集计算中位数，再把同一个值用于验证集；后续做 House Prices 时，我会把预处理放进 Pipeline，避免混淆。

另外，旧版对训练集和测试集分别做票价 `qcut`，会算出不同的分箱边界。同一个档位可能对应不同的票价范围。最新代码已经不用这个特征，但这个问题值得记下来，下次处理其他数据时还会遇到。

现在代码已经加入 `train_test_split`，按 80/20 分层划分训练集和验证集，并能输出 Accuracy 和分类报告。当前导出的 Notebook 默认 `submit = True`，用于训练全量模型并生成 `submission.csv`；需要查看本地验证时切换为 `False`。这次划分使用随机种子 78，模型使用随机种子 91。

## 运行代码

1. 在 [Kaggle Titanic 竞赛](https://www.kaggle.com/competitions/titanic) 中创建 Notebook，并添加竞赛数据。
2. 导入 [notebook9d78c9203f.ipynb](notebook9d78c9203f.ipynb)。代码中的数据目录是 `/kaggle/input/competitions/titanic/`，如果实际路径不同，需要修改两处读取路径。
3. 从头运行全部单元格，将生成的 `submission.csv` 提交到竞赛。

输出包含 `PassengerId` 和 `Survived` 两列，后者为 0 或 1。仓库保留的是 Kaggle 导出的原始代码；README 会随着后续实验继续更新。
